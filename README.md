# Journey to the Demon King

## AI Usage Disclosure

I used ChatGPT extensively while developing this project. It assisted with planning the
class structure, creating and revising portions of the Java code, explaining Java and Swing
concepts, debugging compilation errors, and reviewing the project against the requirements.

ChatGPT also assisted with the battle system, inventory and item system, save and load
system, graphical interface, character animations, UML diagram, project explanation, and
generated artwork for some game assets. The project was developed incrementally, and the
resulting code was compiled and tested throughout development.

I am responsible for reviewing the submitted work and for understanding and explaining its
classes, methods, relationships, and behavior during the project defense.
