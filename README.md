# Journey to the Demon King

## AI Usage Disclosure

I used ChatGPT extensively throughout the development of this project. It helped me plan the class structure, write and improve parts of the Java code, understand Java and Swing concepts, fix compilation errors and check whether the project met the requirements.

ChatGPT also assisted with implementing the battle system, inventory and item system, save and load functionality, graphical user interface, character animations and UML diagram. I also used it to help explain the project and generate artwork for some game assets.

Additionally, I used AntiGravity for code autocomplete during development.

The project was developed step by step, with the code compiled and tested throughout the process. I reviewed the final output and take responsibility for the submitted work. I also understand how the classes, methods and other components work together and am prepared to explain them during the project defense.
